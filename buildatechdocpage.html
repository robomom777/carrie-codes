JavaScript and Java

JavaScript is a versatile programming language primarily used to create dynamic and interactive web applications. Below is a concise guide to help you get started with JavaScript.

JavaScript supports both client-side and server-side development, making it a full-stack tool.

  • Keep your code modular by using functions and external files.
Constants

In JavaScript, a constant is a variable declared with the const keyword whose value cannot be reassigned after initialization.

This means you must assign a value at the time of declaration, and any attempt to reassign it later will throw a TypeError.

  • For example, const PI = 3.14; is valid, but PI = 5; will fail. const variables have block scope (similar to let) and cannot be redeclared.
Data types

JavaScript data types define the kind of values a variable can hold and how those values behave in code. They are broadly divided into primitive and non-primitive types. Primitive types store single, immutable values directly in memory and include Number.

These types are fundamental and cannot be changed after creation.

  • Non-primitive types are objects that can hold complex or multiple values.
Declaring variables

JavaScript variables are containers for storing data values, and they can be declared using let, const, or the older var keyword.

The modern best practice is to use let for variables whose values can change and const for variables that should remain constant, though objects can still be mutated.

  • When naming variables, JavaScript rules require that names start with a letter, underscore (_), or dollar sign ($), and they are case-sensitive.
Variable scope

JavaScript variable scope defines where in the code a variable can be accessed and how long it remains available during execution.

Global scope: Variables declared outside any function or block (with var, let, or const) are accessible anywhere in the script, both inside and outside functions.

  • Function (local) scope: Variables declared inside a function with var are accessible only within that function, and let/const in a function are also limited to that function's block.
